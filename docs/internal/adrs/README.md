BE CONCISE! An ADR is not a spec! No redundancies! Every word tell.

adr_0000.md contains the index, add a row there when you add an ADR.

Naming scheme is `adr_NNNN.md` — no slug so two branches independently claiming "adr_0008" then collide as a real git merge conflict. Observed failure `0002-a.md` and `0002-b.md` in the past.
